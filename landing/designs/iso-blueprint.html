§1

Scope

CLAUSE 1 · FOUR ASSEMBLIES · SHEET REF A-01

The scope of supply: four primary assemblies, each operating entirely on the local device. No network interface is required for any function listed below.

1.1

Document Editor

Merge, split, rotate and organize pages. Drag, drop, reorder — every operation inside a local tab.

1.2

OCR Engine

Tesseract ships as bundled WASM. Recognize text fully offline — not one request leaves the device.

1.3

Redaction

Content-stream purging with verification. What is removed stays removed — measured and confirmed.

1.4

Batch Queue

Queue entire folders and let the pipeline run sequentially on your own hardware, unattended.

ALSO ON BOARD: COMPRESS · SHA-256 SIGNATURES · PASSWORD ENVELOPES · PDF/A ARCHIVING · ZIP BUNDLES
