MAN PAGES

Four entries from the built-in manual. Every command runs in local memory — nothing phones home, ever.

LD-ORGANIZE(1)tools
NAME

organize — merge, split, rotate, reorder

SYNOPSIS

localdesk organize in.pdf --extract 3-5 --rotate 90

DESCRIPTION

Rebuild documents page by page: merge many into one, split by range, rotate and reorder — all without a single server round-trip.

LD-OCR(1)tools
NAME

ocr — make scans searchable, offline

SYNOPSIS

localdesk ocr scan.png --lang eng+deu

DESCRIPTION

Tesseract ships bundled as WebAssembly and runs fully offline: 100+ languages, image preprocessing, searchable PDF out. No API keys, no upload.

LD-REDACT(1)tools
NAME

redact — true removal, not ink

SYNOPSIS

localdesk redact in.pdf --purge-streams --verify

DESCRIPTION

A black box over text is not redaction. Local Desk purges matches from the content streams, rewrites the file, then re-parses it to verify the strings are gone.

LD-BATCH(1)tools
NAME

batch — queues, signatures, envelopes

SYNOPSIS

localdesk batch ./inbox --pipeline convert,sign

DESCRIPTION

Queue hundreds of files across all 22 tools. Attach SHA-256 signatures, wrap outputs in password envelopes, export bundles as PDF/A or ZIP.
