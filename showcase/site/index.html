02 CONVERT

PDF ⇄ Office, without the upload.

Turn PDFs into Word documents with real bordered tables and headings, into Excel worksheets with columns rebuilt from text positions, or into PowerPoint slides with editable text beside each page. Word, Excel and PowerPoint files convert the other way into clean PDFs. Parsing happens in memory on your device — there is no server to send files to.

Scanned PDFs? OCR runs locally too — the English language model ships inside the installer, so recognition works with the internet completely off. Verify it yourself: npx tsx scripts/verify_offline_ocr.ts

04 PRIVACY

Offline isn't a promise. It's enforced.

Local Desk blocks every outbound request at the engine level: anything that isn't a local file is cancelled before it can leave. No updater, no analytics, no account server — and no premium tier that changes that. The enforcement lives in about 40 lines of electron/main.cjs. Go read them — that's the point of open source. Even in browser mode, nothing touches a CDN: every asset, including the OCR engine and its language model, loads from local files.
