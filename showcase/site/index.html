Privacy by Design

No uploads · No accounts · No cloud

Completely free, open source and portable.

No uploads

Every PDF, Word, Excel, PowerPoint, and image file is parsed and modified in local memory on your machine.

No accounts

Launch the studio and start working without sign-ups, subscriptions, or telemetry trackers.

No cloud

The Windows desktop app enforces a session-level outbound network guard and bundles OCR WebAssembly locally.

Precision PDF Editor

Edit real PDF text, fonts, shapes and images right on a precision canvas.

Privacy Redactor

Cover, blur or permanently delete anything sensitive.

Effortless Conversions

Convert to and from Word, Excel, PowerPoint, images and HTML.

Batch Operations

Merge, split, reorder, compress, lock and unlock — even in batches.

Clone & run locally

Run the full web studio locally on Windows, macOS, or Linux with Node.js 18+. 

git clone https://github.com/rehanmumtaz/local-desk.git
cd local-desk && npm install
npm run dev
